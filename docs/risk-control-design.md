# 交易系统风控设计方案

## 一、用户级风控

### 1. 交易频率限制
| 类型 | 阈值 | 策略 |
|------|--------|------|
| 订单提交频率 | 100笔/秒/用户 | 超限拒绝订单 |
| 撤单频率 | 50笔/秒/用户 | 超限拒绝撤单 |
| API调用频率 | 200次/秒/用户/IP | 返回 429 Too Many Requests |

### 2. 订单数量限制
| 类型 | 阈值 |
|------|--------|
| 挂单总数 | 200单/用户/交易对 |
| 单笔数量 | 不超过账户余额 |
| 日交易量 | 10,000 USDT/天/用户 |

### 3. 价格限制
| 类型 | 策略 |
|------|------|
| 价格合理性 | 限制偏离最新成交价 ±50% |
| 最小价格粒度 | 根据交易对配置 (e.g., 0.01 USDT) |
| 最大价格范围 | 交易所规定的上下限 |

### 4. 黑名单/冻结账户
- 恶意用户自动冻结
- 异常行为检测（刷单、对敲）
- 手动冻结接口

---

## 二、订单级风控

### 1. 订单验证
```java
// 验证项
- 数量 > 0
- 价格 > 0
- 符合最小价格/数量精度
- 符合最大单笔金额限制
- 检查余额充足
```

### 2. 时间限制
- IOC (Immediate or Cancel): 10ms 内必须成交否则拒绝
- FOK (Fill or Kill): 100ms 内必须全部成交否则拒绝
- GTC (Good Till Cancel): 有效期检查

### 3. 自成交预防
- 同一用户的买单/卖单不撮合
- 关联账户（子账户）之间不撮合

---

## 三、市场级风控

### 1. 异常波动检测
| 指标 | 触发条件 | 处理方式 |
|------|----------|----------|
| 短时间暴涨 | 5分钟涨幅 > 20% | 暂停交易、通知运维 |
| 异常大单 | 单笔 > 5% 深度 | 人工审核 |
| 成交量异常 | 1分钟 > 日均 10倍 | 风险警报 |

### 2. 对敲检测
- 监控同一 IP 多个账户频繁交易
- 检测反向对冲交易
- 识别洗钱模式

### 3. 刷单检测
- 频繁小单撤单
- 市价扫盘后立即撤单
- 异常高频挂单撤单

---

## 四、系统级风控

### 1. 服务保护
| 类型 | 策略 |
|------|------|
| 熔断机制 | 错误率 > 10% 触发熔断 |
| 降级策略 | 负载过高时关闭非核心功能 |
| 限流保护 | 单机 TPS > 100,000 时拒绝新请求 |

### 2. 数据一致性
- WAL 写入失败拒绝订单
- 订单簿状态异常时暂停撮合
- 数据回滚机制

### 3. 安全防护
- 防止重放攻击 (timestamp + nonce)
- API 签名验证
- SQL 注入/XSS 防护

---

## 五、实现优先级

| 优先级 | 功能 | 紧急程度 |
|--------|------|----------|
| P0 | 订单数量限制、余额检查 | 高 |
| P0 | 交易频率限制 | 高 |
| P1 | 价格合理性检查 | 中 |
| P1 | 自成交预防 | 中 |
| P2 | 异常波动检测 | 低 |
| P2 | 对敲检测 | 低 |
| P3 | 熔断降级 | 低 |

## 六、待实现的风控组件

### 核心接口
```java
// 风控检查器接口
public interface RiskChecker {
    RiskCheckResult checkOrder(Order order);
    RiskCheckResult checkCancel(String orderId, String userId);
}

// 结果返回
public class RiskCheckResult {
    boolean allowed;       // 是否允许
    String rejectReason;   // 拒绝原因
    int errorCode;         // 错误码
}
```

### 计划实现的风控检查器
1. UserRateLimitChecker - 用户频率限制
2. OrderAmountLimitChecker - 订单数量限制
3. PriceRangeChecker - 价格范围检查
4. BalanceChecker - 余额检查
5. SelfTradeChecker - 自成交检查（已部分实现）
6. MarketVolatilityChecker - 市场波动检测
7. WashTradeDetector - 对敲检测
